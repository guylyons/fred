# Magit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Build the approved status-centered Git component and `Space m` namespace inside Fred.

**Architecture:** Use Git CLI subprocesses with structured arguments. A `magit` module owns repository snapshots, row identities, patches, and operations. Editor routes keys, Session owns component buffers and jobs, and App handles interactive terminal handoff.

**Tech Stack:** Rust 2024, standard library, existing Ratatui and tempfile dependencies; no new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-03-magit-design.md`

## Global Constraints

- Support inline and fullscreen Fred; preserve open buffers and unsaved changes.
- All global entry points use Space m: s status, p push, P pull, f fetch, c commit, l log, b branches.
- Operate on disk and the index; never automatically save source buffers.
- Use structured Git arguments, NUL-delimited status, and original path bytes.
- Generated views are read-only and have no swap files. Commit drafts are recoverable editable state-directory files.
- Pull is fast-forward only; push never forces or creates upstream configuration automatically.
- Background reads must not block UI or overwrite newer repository state.

## Review Focus

- A file both staged and unstaged must expose independent actions for each side (Task 1 and 2).
- Deletion-only hunks, no final newline, and non-UTF-8 names must preserve exact index bytes (Task 2).
- A pending refresh arriving after a buffer/repository switch must not replace that buffer (Task 4).
- A hook or authentication failure must restore the terminal and retain a commit draft (Task 5).
- Closing/reopening a generated view must not lose an unsaved source buffer or create source-file swap state (Task 4).

## File Responsibilities

- `src/magit/mod.rs`: component state, actions, stable row identities, collapsed state, and view construction.
- `src/magit/repo.rs`: Git commands, status/history/branch data, index operations, and patch extraction.
- `src/magit/tests.rs`: real temporary repository tests and component state checks.
- `src/lib.rs`: module export.
- `src/vim/mod.rs`, `src/editor.rs`, `src/ex/mod.rs`: prefix parsing, component key routing, and effects.
- `src/session.rs`: component buffer lifecycle, jobs, draft paths, and result application.
- `src/pick/mod.rs`: branch picker using existing picker navigation.
- `src/app.rs`: Git terminal handoff and job ticks.
- `src/ui/render.rs`, `src/ui/tests.rs`: status/diff colors and UI checks.
- `tests/e2e.rs`, `README.md`: terminal regression coverage and usage.
