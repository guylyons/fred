# fred Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `fred`, an inline (non-fullscreen) terminal editor with vim keys, ed-style `:` commands, auto completion, syntax highlighting and crash-safe file handling.

**Architecture:** A library crate holds a terminal-free core (`Buffer` → `Editor` driven by `vim`/`ex` engines, plus `fileio`, `swap`, `highlight`, `complete`). A thin `ui` module renders the `Editor` into a ratatui `Viewport::Inline`, and `main.rs` runs the event loop, signals and recovery prompt.

**Tech Stack:** Rust 2024, ropey 1, ratatui 0.30 + crossterm 0.29, syntect 5 + two-face 0.5, regex 1, unicode-segmentation/width, ignore, toml/serde, signal-hook, libc. Dev: tempfile, portable-pty.

**Spec:** `docs/superpowers/specs/2026-10-01-fred-design.md`

Toolchain: `export PATH="$HOME/.rustup/toolchains/stable-aarch64-apple-darwin/bin:$PATH"` (cargo is not on PATH otherwise).

## Global Constraints

- Every text change goes through `Buffer::apply(Edit)`; vim/ex never touch the rope.
- Rope holds `\n` only; line ending style, final newline and BOM are restored on write.
- Cursor is always on a grapheme boundary; display columns via `unicode-width`, tabs expand to `tabstop` (default 8).
- Window = `height` (default 12) text rows + status row + command row, clamped to `terminal_rows - 2`.
- Errors in the editor are shown as `? message` on the command row; only startup errors exit (code 1).
- Swap dir `$XDG_STATE_HOME/fred/swap/` (default `~/.local/state/fred/swap/`); config `$XDG_CONFIG_HOME/fred/config.toml`.
- No `unwrap()` on I/O paths.

## Review Focus

1. Wide/combining Unicode (`é` as e+U+0301, `漢`, emoji): `l`/`h`/`x` move/delete whole graphemes, and the cursor's screen column accounts for double width → tests in Task 1 and Task 6.
2. Empty and one-line buffers: `dd` on the only line leaves one empty line, `x`/`J`/`G`/`p` on an empty buffer don't panic → tests in Task 5/6.
3. Unchanged round trip is byte-identical (CRLF, no final newline, BOM) → test in Task 7.
4. Bad ex addresses (`100d` in a 10-line file, `5,3d`, `/nomatch/d`) return an error and leave the buffer untouched → tests in Task 4.
5. A killed or crashed session leaves a recoverable swap and the original file untouched → tests in Task 8 and Task 14.

### Task 13: Main loop, terminal lifecycle, recovery prompt

**Files:** Modify `src/main.rs`; create `src/ui/term.rs`, `src/app.rs`.

**Interfaces — Consumes:** everything above. **Produces:** the `fred` binary.

`app::run(args, cfg) -> anyhow::Result<i32>`:
1. Check `isatty(0)` and `isatty(1)` → else `fred: not a terminal`, 1.
2. `fileio::load` (startup errors → `fred: <path>: <err>`, exit 1). Swap check: live owner → prompt `[o]pen read-only, [q]uit`; stale → `[r]ecover, [d]elete, [q]uit` (prompt drawn on the command row of the window; single key answer).
3. Enter raw mode; `Terminal::with_options(CrosstermBackend::new(stdout), TerminalOptions { viewport: Viewport::Inline(h) })`; remember viewport origin.
4. Loop: `event::poll(50ms)`; key → `ed.handle_key`; resize → rebuild terminal (clear from origin `ClearType::FromCursorDown`, new Inline viewport); after each key run `pending_effect` (write: `fileio::write(path, buf.to_bytes(), stamp, force)`, success message `"name" 12L, 340B written`, set `written=true`; quit; edit file); idle tick: swap write when `modified && (1s since last edit || edits_since_swap>=200)`, highlight continuation, nearby-word refresh; `Ctrl-Z` → leave raw mode, `libc::raise(SIGTSTP)`, on return re-enter raw mode, rebuild viewport, check `changed_on_disk`.
5. Signals: `signal_hook::flag::register` for SIGHUP/SIGTERM sets an `AtomicBool`; loop sees it → write swap, restore terminal, exit 1.
6. Panic hook: restore terminal (disable raw mode, show cursor), print message. Swap is written by the loop on a `catch_unwind` boundary around `handle_key` (catch, write swap, re-panic).
7. Exit: clear viewport rows, move cursor to origin, disable raw mode; if `written` print the summary line; remove swap.
